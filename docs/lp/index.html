Chatwork のタイムラインは、複数の話題が時系列に混ざって流れていきます。 この拡張は表示中の返信関係を読み取り、画面の右側にスレッドの一覧を出します。 Chatwork の画面自体は何も変えません。横に増えるだけです。

画面から読み取る

プライバシー

送信するものが、ひとつもない。

会話の中身がどこかへ送られることはありません。送る相手も、送る道もない。 理由は次の 4 つです。

—

データを送り出す機能が、そもそもありません

外へ情報を送るための処理を一切書いていません。送る先のサーバーも用意していません。

—

パスワードや鍵には触れません

Chatwork のログイン情報を読むことはありません。見るのは、あなたの画面にいま表示されている文字だけです。

—

メッセージはどこにも残りません

読み取った内容はその場で表示に使うだけ。残すのはパネルの幅と、開いているかどうか。この 2 つだけです。

—

誰が何を見たかを数えていません

利用状況を集める仕組みも、広告も入っていません。集める先がないので、集めようがない。

保存するもの: パネルの幅と開閉状態だけ
動くページ: Chatwork のみ
外から読み込むもの: なし（すべて拡張機能の中に入っています）

先に言っておきます。以下は仕様です。直せる不具合ではありません。

読み込まれている範囲だけが対象です

Chatwork は過去ログを順に読み込みます。上へスクロールして読み込んだ範囲でスレッドが復元されます。範囲外に親がある返信は、その旨を示したうえで単独のスレッドとして扱います。

別ルームへの返信はそのルームで解決されます

他のルームのメッセージへの返信は、そのルームを開いたときに親子として結びつきます。

Chatwork の画面構造が変われば止まります

画面から読み取る以上、これは避けられません。動かなくなったらパネルに診断情報を出すので、こちらの不具合か Chatwork 側の変更かは切り分けられます。

返信の送信はできません

この拡張は表示だけを行います。メッセージの送信・編集・削除は一切行いません。

Privacy Policy

プライバシーポリシー

最終更新日: 2026年8月30日

本拡張は、いかなる情報も収集・送信・第三者提供しません。外部サーバーとの通信を行うコードを含んでおらず、すべての処理はお使いのブラウザの中だけで完結します。

1. 本拡張が行う処理

Chatwork のページを表示しているときにのみ動作し、次を行います。

  • 表示中のページから、送信者名・本文・時刻・返信先を読み取る
  • 読み取った情報から返信の親子関係を組み立てる
  • 組み立てた結果を、同じページ上のパネルに表示する

いずれも画面に表示する目的でのみ行われ、読み取った内容がブラウザの外へ出ることはありません。

2. 収集しない情報

  • 氏名、メールアドレス、その他の個人を特定できる情報
  • メッセージの本文および添付ファイル
  • Chatwork のアカウント情報、API トークン、その他の認証情報
  • 閲覧履歴、操作履歴、利用統計
  • IP アドレス、位置情報、端末識別子

3. 端末に保存する情報

Chrome の storage 権限を用いて、次の 2 つのみを端末内に保存します。外部へ送信されることはなく、拡張機能を削除すると同時に消去されます。

保存する値内容
パネルの幅数値（ピクセル）
パネルの開閉状態開いている / 閉じている

4. 第三者への提供

一切行いません。外部との通信を行わないため、提供先が存在しません。

6. 検証方法

ソースコードを公開しています。リポジトリを開き、 fetch / XMLHttpRequest / WebSocket / EventSource / navigator.sendBeacon を検索すると、 いずれも 1 件も見つからないことを確認できます。

本拡張は fetch / XMLHttpRequest / WebSocket / EventSource / navigator.sendBeacon の いずれも使用していません。ソースコードによる確認をご希望の場合は、お問い合わせください。

7. 本ポリシーの変更

内容を変更する場合は、最終更新日を改めたうえで本ページに掲載します。収集する情報を増やす変更を行う場合は、事前に拡張機能の説明欄で告知します。
