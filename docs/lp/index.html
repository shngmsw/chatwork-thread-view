Chrome 拡張機能

流れた会話を、
もう一度たどれるように。

Chatwork のタイムラインは、複数の話題が時系列に混ざって流れていきます。 この拡張は表示中の返信関係を読み取り、会話をスレッドの木構造に組み直します。 「この返信、どれに対するものだったか」を探し直す必要がなくなります。

仕組み

ページを読むだけで、外には出さない。

画面から読み取る

表示中のタイムラインから、送信者・本文・時刻・返信先を読み取ります。API も通信も使いません。

親子関係を組み直す

返信先をたどって根まで遡り、木構造を作ります。循環や親の欠落があっても壊れないようにしています。

横に並べて表示する

右側のパネルに描画します。Chatwork 本体の CSS や JS とは Shadow DOM で隔離しています。

プライバシー

送信するものが、ひとつもない。

この拡張にはバックエンドがありません。解析はすべてブラウザの中で完結します。 技術的に「送れない」設計であることを、次のかたちで担保しています。

—

通信するコードを含んでいません

ソース全体に fetch / XMLHttpRequest / WebSocket / sendBeacon が 1 箇所もありません。

—

認証情報を扱いません

API トークンにもログイン情報にも触れません。読むのは画面に出ている内容だけです。

—

メッセージを保存しません

端末に残すのはパネルの幅と開閉状態の 2 つだけ。拡張を削除すれば同時に消えます。

—

解析ツールも広告も入れていません

利用統計、クラッシュレポート、テレメトリのいずれも組み込んでいません。

読み込まれている範囲だけが対象です

Chatwork は過去ログを順に読み込みます。上へスクロールして読み込んだ範囲でスレッドが復元されます。範囲外に親がある返信は、その旨を示したうえで単独のスレッドとして扱います。

別ルームへの返信はそのルームで解決されます

他のルームのメッセージへの返信は、そのルームを開いたときに親子として結びつきます。

Chatwork の画面構造が変われば止まります

画面から読み取る方式である以上、これは避けられません。動かなくなった場合はパネルに診断情報を表示し、原因の切り分けができるようにしています。

返信の送信はできません

この拡張は表示だけを行います。メッセージの送信・編集・削除は一切行いません。

Privacy Policy

プライバシーポリシー

最終更新日: 2026年8月30日

本拡張は、いかなる情報も収集・送信・第三者提供しません。外部サーバーとの通信を行うコードを含んでおらず、すべての処理はお使いのブラウザの中だけで完結します。

1. 本拡張が行う処理

Chatwork のページを表示しているときにのみ動作し、次を行います。

  • 表示中のページから、送信者名・本文・時刻・返信先を読み取る
  • 読み取った情報から返信の親子関係を組み立てる
  • 組み立てた結果を、同じページ上のパネルに表示する

いずれも画面に表示する目的でのみ行われ、読み取った内容がブラウザの外へ出ることはありません。

2. 収集しない情報

  • 氏名、メールアドレス、その他の個人を特定できる情報
  • メッセージの本文および添付ファイル
  • Chatwork のアカウント情報、API トークン、その他の認証情報
  • 閲覧履歴、操作履歴、利用統計
  • IP アドレス、位置情報、端末識別子

3. 端末に保存する情報

Chrome の storage 権限を用いて、次の 2 つのみを端末内に保存します。外部へ送信されることはなく、拡張機能を削除すると同時に消去されます。

保存する値内容
パネルの幅数値（ピクセル）
パネルの開閉状態開いている / 閉じている

4. 第三者への提供

一切行いません。外部との通信を行わないため、提供先が存在しません。

5. 権限を必要とする理由

権限理由
storage上記のパネル表示設定を保存するため
www.chatwork.comChatwork の画面上で動作し、表示中のメッセージを読み取ってパネルを追加するため
kcw.kddi.ne.jpKDDI が提供する Chatwork でも同様に動作するため

対象は Chatwork のサービス提供ドメインに限定しており、その他のサイトでは動作しません。

6. 検証方法

ソースコードは公開されています。fetch / XMLHttpRequest / WebSocket / EventSource / navigator.sendBeacon のいずれもソースコード中に存在しないことを確認できます。

7. 本ポリシーの変更

内容を変更する場合は、最終更新日を改めたうえで本ページに掲載します。収集する情報を増やす変更を行う場合は、事前に拡張機能の説明欄で告知します。
