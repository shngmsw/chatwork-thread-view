## 説明文 (詳細)

```
Chatwork のタイムラインは、複数の話題が時系列に混ざって流れていきます。
「この返信、どのメッセージに対するものだったか」を追うために、
何度もスクロールして探すことになります。

スレッドビュー for Chatwork は、表示中のタイムラインから返信の親子関係を読み取り、
画面の右側にスレッドツリーとして組み立て直します。


■ できること

・返信の親子関係を解析し、スレッド一覧として表示します
・スレッドを開くと、返信の入れ子構造をツリーで確認できます
・ツリー上のメッセージをクリックすると、タイムラインの該当位置へ移動して一瞬ハイライトします
・返信の本文をクリックすると、パネル内で全文を読めます
・返信の行から、そのメッセージへの返信を Chatwork の入力欄に差し込めます
・スレッドに自分だけの名前を付けられます (端末内に保存されます)
・返信が付いていないメッセージも含めた全件表示に切り替えられます
・ルームの切り替えと、過去ログの追加読み込みに自動で追従します
・ツールバーのアイコンをクリックすると、パネルを開いたり閉じたりできます
・パネルの幅はドラッグで変更でき、次回以降も維持されます
・配色は Chatwork 本体のテーマ (ライト / ダーク) に自動で合わせます


■ プライバシーとセキュリティ

この拡張は、外部のサーバーと一切通信しません。

・ネットワーク通信を行うコードを含んでいません
・API トークンなどの認証情報を一切扱いません
・メッセージの内容を送信しません。保存もしません
・読み取るのは、あなたのブラウザに表示されている画面の内容だけです
・ブラウザに保存するのは、パネルの幅、開閉状態、
　あなたが自分で付けたスレッド名だけです

解析はすべてブラウザの中だけで完結します。


■ 動作の前提と制限

・表示中のタイムラインに読み込まれているメッセージのみが対象です。
　Chatwork は過去ログを順次読み込むため、上へスクロールして読み込んだ範囲で
　スレッドが復元されます。
・読み込み済みの範囲外に親メッセージがある返信は、「親メッセージ未読み込み」の
　表示付きで単独のスレッドとして扱われます。
・別のルームへの返信は、そのルームを開いたときに親子として解決されます。
・Chatwork の画面構造が変更されると動かなくなります。その場合はパネルに
　診断情報を表示するので、どちら側の問題かは切り分けられます。
```

## 権限の justification

デベロッパーダッシュボードの「権限の正当性」欄に貼り付けます。

### storage

```
表示設定と、利用者が自分で付けたスレッド名を端末内に記憶するために
使用します。保存するのは次の 3 つだけです。

・パネルの幅 (数値)
・パネルの開閉状態 (真偽値)
・利用者が自分で入力したスレッド名 (文字列。ルームごとに保存)

スレッド名は利用者自身が入力した文字列であり、メッセージの本文を
保存したものではありません。いずれも端末内にのみ保存し、外部へは
送信しません。
```

### ホスト権限 (https://www.chatwork.com/*, https://kcw.kddi.ne.jp/*)

```
本拡張は Chatwork の画面上で動作します。表示中のタイムラインから返信の
親子関係を読み取り、同じページ内にスレッド表示のパネルを追加するために、
このドメインへのアクセスが必要です。対象は Chatwork のサービス提供
ドメインのみに限定しています (kcw.kddi.ne.jp は KDDI 提供の
Chatwork サービス用ドメインです)。外部への送信は一切行いません。
```

### service worker

```
ツールバーのアイコンが押されたことを、表示中のタブへ伝えるためだけに
使用します。処理内容はメッセージを 1 通送ることのみで、データの読み取り・
保存・送信は一切行いません。常時実行されるものではなく、クリック時にのみ
起動します。
```

### リモートコード

```
使用していません。すべてのコードは拡張機能のパッケージに同梱されています。
外部スクリプトの読み込み、eval、動的なコード生成は行いません。
```

## 画像素材

| 用途 | 必須 | サイズ | 状態 |
| --- | --- | --- | --- |
| ストアのアイコン | 必須 | 128 × 128 PNG | **`docs/store/assets/store-icon-128.png`** |
| 拡張機能のアイコン | 必須 | 16/32/48/128 PNG | `icons/` (ZIP に同梱済み。個別アップロード不要) |
| スクリーンショット | 必須 (1〜5 枚) | **1280 × 800 ちょうど** の PNG | `docs/store/screenshot.html` から生成 |
| 小さなプロモタイル | 任意 | 440 × 280 PNG | `docs/store/assets/promo-small-440x280.png` |
| LP | 任意 | — | `docs/lp/index.html` |
| マーキープロモタイル | 任意 | 1400 × 560 PNG | `docs/store/assets/promo-marquee-1400x560.png` |

プロモタイルはダッシュボード上ではどちらも任意です (developer.chrome.com には
小さい方が必須と書かれていますが、実際の入力欄では任意でした)。
用意はしてあるので、載せるかどうかは任意で決めてください。
生成元は `docs/store/promo-tile.html` です。

### スクリーンショットの撮り方

1. リポジトリ直下で `python -m http.server 8731` を実行する
   (ES モジュールを読むので `file://` では動かない)
2. ブラウザで開いてマゼンタの外枠を目印に切り出す
   - ダーク: `http://127.0.0.1:8731/docs/store/screenshot.html?shot=1`
   - ライト: `http://127.0.0.1:8731/docs/store/screenshot.html?shot=1&theme=light`
3. **1280 × 800 ちょうどに縮小する。** `?shot=1` は既定で 1.25 倍に拡大して
   描画するため、切り出した直後は 1600 × 1000 前後になる。拡大して描いてから
   縮小すると文字が締まる、というのが狙いなので、この縮小は省略できない。
   ストアは 1280 × 800 か 640 × 400 ちょうどしか受け付けない。

**ストアのアイコンには `icons/128.png` ではなく `docs/store/assets/store-icon-128.png`
を使ってください。** ストア側で影などの装飾が付くため、128 × 128 のうち図案は
96 × 96 に収め、周囲 16px を余白にする必要があります。`icons/128.png` は
ツールバー用で canvas いっぱいに描いてあり、ストアに出すと窮屈に見えます。

アイコンは `npm run icons` (`scripts/make-icons.mjs`) で両方とも再生成できます。

**スクリーンショットに実際の業務画面を使わないでください。** 取引先名・実名・
やりとりの内容がそのまま公開されます。`docs/store/screenshot.html` は
実際の UI をサンプルデータで描画するページです。これを 1280 × 800 で
撮影してください。
