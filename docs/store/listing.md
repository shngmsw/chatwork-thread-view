## 説明文 (詳細)

```
Chatwork のタイムラインは、複数の話題が時系列に混ざって流れていきます。
「この返信、どのメッセージに対するものだったか」を追うために、
何度もスクロールして探すことになります。

スレッドビュー for Chatwork は、表示中のタイムラインから返信の親子関係を読み取り、
画面の右側にスレッドツリーとして組み立て直します。


■ できること

・返信の親子関係を解析し、スレッド一覧として表示します
・スレッドを開くと、返信の入れ子構造をツリーで確認できます
・ツリー上のメッセージをクリックすると、タイムラインの該当位置へ移動して一瞬ハイライトします
・返信が付いていないメッセージも含めた全件表示に切り替えられます
・ルームの切り替えと、過去ログの追加読み込みに自動で追従します
・パネルの幅はドラッグで変更でき、次回以降も維持されます
・配色は Chatwork 本体のテーマ (ライト / ダーク) に自動で合わせます


■ プライバシーとセキュリティ

この拡張は、外部のサーバーと一切通信しません。

・ネットワーク通信を行うコードを含んでいません
・API トークンなどの認証情報を一切扱いません
・メッセージの内容を送信しません。保存もしません
・読み取るのは、あなたのブラウザに表示されている画面の内容だけです
・ブラウザに保存するのは、パネルの幅と開閉状態のみです

解析はすべてブラウザの中だけで完結します。


■ 動作の前提と制限

・表示中のタイムラインに読み込まれているメッセージのみが対象です。
　Chatwork は過去ログを順次読み込むため、上へスクロールして読み込んだ範囲で
　スレッドが復元されます。
・読み込み済みの範囲外に親メッセージがある返信は、「親メッセージ未読み込み」の
　表示付きで単独のスレッドとして扱われます。
・別のルームへの返信は、そのルームを開いたときに親子として解決されます。
・Chatwork の画面構造が変更されると動かなくなります。その場合はパネルに
　診断情報を表示するので、どちら側の問題かは切り分けられます。


■ ご利用にあたって

本拡張は Chatwork株式会社 の公式製品ではありません。
Chatwork は Chatwork株式会社 の登録商標です。
名称に含まれる「for Chatwork」は、対応するサービスを示すための表記です。

本拡張の利用によって生じたいかなる損害についても、開発者は責任を負いません。
```

## 単一用途の説明 (Single purpose)

```
Chatwork のタイムラインに表示されている返信の親子関係を解析し、
スレッド構造として同じページ上に表示することを唯一の目的としています。
```

## 権限の justification

デベロッパーダッシュボードの「権限の正当性」欄に貼り付けます。

### storage

```
パネルの幅と開閉状態をユーザーごとに記憶するためだけに使用します。
メッセージの内容や個人情報は一切保存しません。保存する値は
数値 (パネル幅) と真偽値 (開閉状態) の 2 つのみです。
```

### ホスト権限 (https://www.chatwork.com/*, https://kcw.kddi.ne.jp/*)

```
本拡張は Chatwork の画面上で動作します。表示中のタイムラインから返信の
親子関係を読み取り、同じページ内にスレッド表示のパネルを追加するために、
このドメインへのアクセスが必要です。対象は Chatwork のサービス提供
ドメインのみに限定しています (kcw.kddi.ne.jp は KDDI 提供の
Chatwork サービス用ドメインです)。外部への送信は一切行いません。
```

### リモートコード

```
使用していません。すべてのコードは拡張機能のパッケージに同梱されています。
外部スクリプトの読み込み、eval、動的なコード生成は行いません。
```

## データ使用に関する申告 (Privacy practices)

| 収集するデータ種別 | 申告 |
| --- | --- |
| 個人を特定できる情報 | 収集しない |
| 健康情報 | 収集しない |
| 財務・支払い情報 | 収集しない |
| 認証情報 | 収集しない |
| 個人的な通信内容 | **収集しない** (画面上で解析のみ行い、送信・保存しない) |
| 位置情報 | 収集しない |
| ウェブ閲覧履歴 | 収集しない |
| ユーザーの操作履歴 | 収集しない |
| ウェブサイトのコンテンツ | **収集しない** (同上) |

チェックが必要な 3 つの宣言（すべて該当します）:

- [x] 承認された用途にのみデータを使用します
- [x] 第三者への販売・譲渡を行いません
- [x] 承認された用途以外の目的での利用・転送を行いません

> 補足: 本拡張はメッセージ内容を「読み取り」ますが、それはブラウザ内で表示を
> 組み立てるためだけであり、収集 (collect) には該当しません。外部送信も
> 永続保存も行いません。審査で説明を求められた場合は、ソースコードに
> `fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon` が 1 箇所も
> 存在しないことを示してください。
