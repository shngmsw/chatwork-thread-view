# プライバシーポリシー — スレッドビュー for Chatwork

最終更新日: 2026年8月30日

## 結論

**本拡張は、いかなる情報も収集しません。外部への送信も、第三者への提供も行いません。**

外部サーバーとの通信を行うコードを含んでいません。すべての処理は、
お使いのブラウザの中だけで完結します。

---

## 1. 本拡張が行う処理

本拡張は、Chatwork のページを表示しているときにのみ動作し、次の処理を行います。

1. 表示中のページから、メッセージの送信者名と本文、時刻、返信先を読み取る
2. 読み取った情報から返信の親子関係を組み立てる
3. 組み立てた結果を、同じページ上のパネルに表示する

これらはすべて、画面に表示する目的でのみ行われます。読み取った内容が
ブラウザの外へ出ることはありません。

## 2. 収集しない情報

本拡張は以下を **収集しません**。

- 氏名、メールアドレス、その他の個人を特定できる情報
- メッセージの本文および添付ファイル
- Chatwork のアカウント情報、API トークン、その他の認証情報
- 閲覧履歴、操作履歴、利用統計
- IP アドレス、位置情報、端末識別子

本拡張には解析ツール、広告、クラッシュレポート、テレメトリの類を
一切組み込んでいません。

## 3. ブラウザに保存する情報

Chrome の `storage` 権限を用いて、以下の 2 つの値のみをお使いの端末内に保存します。

| 保存する値 | 内容 |
| --- | --- |
| パネルの幅 | 数値 (ピクセル) |
| パネルの開閉状態 | 開いている / 閉じている |

これらは表示設定を次回以降も維持するためのものです。端末内にのみ保存され、
外部へ送信されることはありません。拡張機能を削除すると同時に消去されます。

## 4. 第三者への提供

一切行いません。本拡張は外部との通信を行わないため、提供先が存在しません。

## 5. 権限を必要とする理由

| 権限 | 理由 |
| --- | --- |
| `storage` | 上記のパネル表示設定を保存するため |
| `https://www.chatwork.com/*` | Chatwork の画面上で動作し、表示中のメッセージを読み取ってパネルを追加するため |
| `https://kcw.kddi.ne.jp/*` | KDDI が提供する Chatwork でも同様に動作するため |

対象ドメインは Chatwork のサービス提供ドメインに限定しています。
その他のサイトでは本拡張は動作しません。

## 6. 検証方法

本拡張は以下のいずれの API も使用していません。
ソースコードを公開している場合は、リポジトリを検索することで確認できます
（公開先: 未確定。公開したら URL をここに記載すること）。

- `fetch`
- `XMLHttpRequest`
- `WebSocket`
- `EventSource`
- `navigator.sendBeacon`

## 7. 本ポリシーの変更

内容を変更する場合は、本ページの最終更新日を改めたうえで掲載します。
収集する情報を増やす変更を行う場合は、事前に拡張機能の説明欄で告知します。
